# capistone-report

## 프로젝트 소개
일상생활에서 시간적 제약으로 인해 직접 처리하기 어려운 업무를 다른 사용자에게 의뢰할 수 있는 심부름 서비스 애플리케이션입니다. 
관공서 물품 수령, 도서 반납 등 일상에서 발생하는 불편함을 해결하고, 의뢰인과 수행자가 서로 소통하며 업무를 진행 할 수 있는 서비스를 목표로 제작했습니다.

* **프로젝트 유형** : 캡스톤 디자인 팀 프로젝트
* **개발 기간** : 2025.03.05 ~ 2025.06.18
* **개발 도구** : MIT App Inventor
* **주요 기술** : 블록 코딩, Firebase, 지도 컴포넌트
* **담당 역할** : 김지원(지도 위 핀 마커), 고금비(작성 게시글, 실시간 대화방, 로그인, 회원가입), 변채원(초기 디자인, 알림, 검색), 조수현(순서도, 신뢰도, 마이페이지)

## 개발 배경 및 목표

### 개발 배경
관공서 운영시간과 직장인의 근무시간이 겹치거나, 개인적인 사정으로 인해 필요한 업무를 직접 처리하기 어려운 상황이 발생합니다. 특히 1인 가구는 업무를 대신 부탁할 사람이 부족할 수 있습니다.
이러한 불편함을 해결하기 위해 필요한 업무를 등록하고, 다른 사용자와 연결하여 의뢰를 진행할 수 있는 심부름 서비스 앱을 기획했습니다.

### 개발 목표
* 간편한 심부름 의뢰 및 게시물 탐색
* 의뢰인과 수행자 간 원활한 소통
* 사용자 신뢰도 확인을 통한 의뢰 환경 마련
* 다양한 연령층이 쉽게 사용할 수 있는 직관적인 UI 구성

## 주요 기능
### 회원 가입 및 로그인
* 사용자 계정 생성 및 로그인
* 입력 정보 검증
* 입력값이 올바르지 않은 경우 오류 메시지 처리

### 의뢰 게시판
* 필요한 업무를 게시물로 작성
* 게시물 확인 및 검색
* 의뢰 내용과 완료 기한을 바탕으로 업무 탐색

### 신뢰도 시스템
* 사용자 신뢰도를 점수로 표시
* 평가 결과에 따라 신뢰도 점수 변경

**점수 산정 기준**
* 기본 점수 : 2.5점
* 좋아요 : +0.1점
* 싫어요 · 업무 미수행 : -0.1점

### 지도 기반 위치 확인
* 지도에서 특정 위치 선택
* 지도 터치 이벤트를 통해 위도와 경도 확인
* 선택한 위치에 마커 생성

### 실시간 채팅
* Firebase를 이용한 메시지 저장 및 불러오기
* 타이머를 활용한 주기적인 메시지 확인
* 의뢰인과 수행자 간의 업무 관련 소통

## 개발 중 문제 해결
### 회원가입 입력 오류 처리
**문제사항** 
회원가입 시 필수 입력값이 비어 있거나 잘못된 정보를 입력했을 때 표시되는 오류 메시지가 화면에서 벗어나는 과정에서 예상과 다르게 동작하는 문제가 발생했습니다.

**개선 방향**
입력값 검증과 화면 이동에 따른 오류 메시지 처리 시점을 점검하고, 페이지 이동 후에도 검증 결과가 적절하게 처리되도록 구체화합니다.

### Firebase 연동 문제
**문제사항**
Firebase의 URL과 토큰을 입력헀음에도 데이터 연동이 정상적으로 이루어지지 않는 문제가 발생했습니다.

**원인 및 해결**
개발 환경과 Firebase 연동 지원 여부를 확인 한 결과, 사용 중인 ios환경에서 발생하는 호환성 문제가 원인임을 확인했습니다. 이후 Android 환경으로 변경하여 연동 문제를 해결했습니다.

### 지도 마커 생성
**구현과정**
MIT App Inventor에서 제공하는 지도 컴포넌트와 Map Touched 이벤트를 활용했습니다. 사용자가 지도의 특정 위치를 터치하면 해당 위치의 위도와 경도를 확인하고 마커를 생성하도록 구현했습니다.

## 프로젝트 회고
이번 프로젝트를 통해 블록 기반 프로그래밍으로 모바일 애플리케이션의 화면과 기능을 구현하는 경험을 쌓았습니다.
특히 사용자 신뢰도 시스템을 설계하고, 지도 컴포넌트와 Firebase를 연동하는 과정에서 기능의 동작 흐름과 데이터 처리 방식을 이해할 수 있습니다.
또한 개발 환경에 따른 호환성 문제와 입력값 검증 오류를 경험하며, 기능을 구현하는 것뿐만 아니라 다양한 상황에서 정상적으로 동작하는지 확인하는 과정이 중요하다는 점을 배웠습니다.
