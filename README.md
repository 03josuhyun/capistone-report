# capistone-report

## 프로젝트 소개
일상생활에서 시간적 제약으로 인해 직접 처리하기 어려운 업무를 다른 사용자에게 의뢰할 수 있는 심부름 서비스 애플리케이션입니다. 
관공서 물품 수령, 도서 반납 등 일상에서 발생하는 불편함을 해결하고, 의뢰인과 수행자가 서로 소통하며 업무를 진행 할 수 있는 서비스를 목표로 제작했습니다.

* **프로젝트 유형** : 캡스톤 디자인 팀 프로젝트
* **개발 기간** : 2025.03.05 ~ 2025.06.18
* **개발 도구** : MIT App Inventor
* **주요 기술** : 블록 코딩, Firebase, 지도 컴포넌트
* **담당 역할** : 김지원(지도 위 핀 마커), 고금비(작성 게시글, 실시간 대화방, 로그인, 회원가입), 변채원(초기 디자인, 알림, 검색), 조수현(순서도, 신뢰도, 마이페이지)

## 개발 배경 및 목표

### 개발 배경
관공서 운영시간과 직장인의 근무시간이 겹치거나, 개인적인 사정으로 인해 필요한 업무를 직접 처리하기 어려운 상황이 발생합니다. 특히 1인 가구는 업무를 대신 부탁할 사람이 부족할 수 있습니다.
이러한 불편함을 해결하기 위해 필요한 업무를 등록하고, 다른 사용자와 연결하여 의뢰를 진행할 수 있는 심부름 서비스 앱을 기획했습니다.

### 개발 목표
* 간편한 심부름 의뢰 및 게시물 탐색
* 의뢰인과 수행자 간 원활한 소통
* 사용자 신뢰도 확인을 통한 의뢰 환경 마련
* 다양한 연령층이 쉽게 사용할 수 있는 직관적인 UI 구성
